# TASK 05: LUỒNG CÀI ĐẶT & QUYỀN RIÊNG TƯ

## 1. Objective
Xây dựng các màn hình cài đặt cấu hình từ Tab Menu.

## 2. Screens to Implement
### 2.1. Cài đặt chung (`settings_screen.dart`)
- **UI Elements:** Giao diện List danh sách các mục: "Đổi mật khẩu", "Cài đặt thông báo", "Chặn", "Đăng xuất".

### 2.2. Danh sách Chặn (`block_list_screen.dart`)
- **UI Elements:** Nút "Thêm vào danh sách chặn". Bên dưới là danh sách các User đã chặn kèm nút "Bỏ chặn".

### 2.3. Cài đặt Thông báo (`push_settings_screen.dart`)
- **UI Elements:** Danh sách các loại thông báo (Bình luận, Lời mời kết bạn, Sinh nhật...). Sử dụng Switch (Nút gạt Bật/Tắt) cho từng mục.

### 2.4. Đổi mật khẩu (`change_password_screen.dart`)
- **UI Elements:** 3 TextField (Mật khẩu hiện tại, Mật khẩu mới, Gõ lại mật khẩu mới). Nút "Lưu thay đổi".
